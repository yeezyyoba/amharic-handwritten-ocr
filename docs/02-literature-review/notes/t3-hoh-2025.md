## Problem
 
The authors say note-taking apps and traditional OCR handle handwriting, rotated photos and noisy images badly. They build an Android app that turns photos of printed or handwritten text into editable notes, and they say it should replace plain OCR with a machine-learning one.
 
## Method
 
The app was developed with Rapid Application Development (requirements planning, user design, construction, cutover). The flow is:
 
- the user registers or logs in;
- takes a photo or picks one from the gallery
- gets the recognised text, which can be edited and saved as a note
- exports the note as .txt and shares it.
The text recognition comes from the OCR service in Huawei ML Kit (Section 3.1.1). Section 4.2 explains backpropagation in general terms and does not describe a model trained by the authors. The app needs Android 8.0 or later and was tested on a phone running Android 11.
 
## Data
 
No dataset is described. The screenshots show printed text and a handwritten whiteboard note in English. The number of test images, the number of writers and the handwriting conditions are not given.
 
## Evaluation
 
The paper compares "traditional OCR" with "OCR with machine learning" on printed and handwritten images, each also rotated 180°. "Accuracy" is not defined and the traditional engine is not named. 
 
## Key results
 
| Text | Traditional OCR | OCR with ML |
|---|---|---|
| Printed | 86.7% | 96.3% |
| Printed, rotated 180° | 55.3% | 89.7% |
| Handwritten | 54.5% | 84.1% |
| Handwritten, rotated 180° | 33.7% | 64.8% |

## Strengths
 
- It is the closest paper I found to our flow: photo, editable text, save, export.
- It tests handwriting and rotated images, and it includes a user test.
- The architecture and screens are shown, and the paper is open access.

## Weaknesses
 
- The baseline engine is not named, "accuracy" is not defined, and the number of test images is not given.
- The recogniser is a vendor service, so the paper says little about how recognition works. It also does not say whether the on-device or the cloud mode was used.

## Relevance to our project

- **The OCR service sets which languages the app can read.** Huawei's text recognition page (last updated 2026-01-08, accessed 2026-11-22) lists Simplified Chinese, Japanese, Korean and Latin-based languages for the on-device mode. The cloud mode lists more languages, such as Arabic, Hindi and Thai, but not Amharic. An app built on this service would not cover Amharic, which is a reason for our own model behind a backend.
- **Keeping notes on the phone is an option.** ScanNote stores notes in a local database and uses a web service for the rest.
